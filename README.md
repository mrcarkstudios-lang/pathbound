# PATHBOUND (game)

Three.js + Vite. Plan Maria's route tile by tile, press PLAY, watch it run.

    npm install
    npm run dev        # http://localhost:5173
    npm test           # replays all 200 stored solutions through src/sim.js
    npm run build      # static site in dist/ (deploy this folder to Vercel)

Debug URL options: `?level=40` open a level, `&auto=1` play its stored solution, `&moves=RRDW` play given moves, `&fast=1` double speed, `?unlock=1` unlock every level.

Controls: tap or drag tiles to draw the route, tap the last tile again to wait, Undo / Clear / PLAY / speed / View (rotate camera) / Hint. Keyboard: arrows or WASD, Space, Backspace or Z, Enter, Q and E.

Assets in `public/assets` are generated by `node tools/convert-assets.mjs <folder with the unzipped packs>`.
Level data `src/data/levels.json` is a copy of `../design/levels.json`.

Art: `node tools/process-art.mjs <raw folder>` builds `public/art` from the generated images; `node tools/make-art-prompts.mjs` rebuilds the Gemini prompt list.
Ads and shop: `src/ads.js`, `src/ads-config.js` (Google test ids), `src/economy.js`, `src/iap.js`. `?ads=sim` shows fake ads on any build.

Full documentation: `../docs/GAME_BUILD_DOCUMENTATION.md`, `../docs/ART_AND_UI_PIPELINE.md`, `../docs/MONETIZATION_AND_ADS_PLAN.md`.
